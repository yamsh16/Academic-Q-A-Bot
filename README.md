# Academic-Q-A-Bot
An AI-powered Python web app that transforms academic documents into study-ready question &amp; answer pairs. Upload a PDF, DOCX, or TXT file, choose your difficulty level (Easy / Medium / Hard), and the app extracts the content, sends it to the Groq API, and uses Meta's LLaMA 3.3 70B model to generate categorized Q&amp;A pairs.
